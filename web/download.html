本版更新（v1.18.0）

  • 新增：完整音质体系，支持 128K / 192K / 320K / FLAC / FLAC 24bit / Hi-Res / Atmos / Atmos+ / Master，并新增对应彩色徽章
  • 新增：安卓原生锁屏显示——设置项「锁屏显示」，一键直达 MIUI/HyperOS 锁屏显示权限页，锁屏歌词/播放控制
  • 修复：桌面歌词多行模式不逐字、翻译不显示——原生自绘歌词行，歌词逐字染色 + 翻译小字同行显示
  • 新增：全平台逐字歌词兜底（无逐字歌词的音源按行时间自动生成），并统一歌词时间轴精度
  • 升级：音效系统新增人声增强 / 超重低音 / 3D 环绕 / 现场 / 电子 / 摇滚 / 民谣 / 古典 / 爵士 / 影院 / 音乐厅等 12 组预设，新增响度增强与可重置均衡器
  • 修复：设置 Master 却显示 FLAC 的徽标问题，回退档位时不再错误显示
  • 继承：一键下载歌单、本地音乐独立页面、WebDAV 修复、赞助码居中

历史版本说明见源码包内 doc/mod-features.md。

源码 / 自建一起听

基于 lyswhut/lx-music-mobile 修改；部分功能移植自 LX-X Music，详见关于页引用项目。源码已托管 GitHub：

  • App 源码：yzdz666/lx-music-mobile-mod
  • 服务端 / 网页版源码：yzdz666/listen-together-server
下载二改源码（打包版）含 listen-together-server 与全部二改代码（不含签名密钥） 管理后台上传安装包 / 源码 / 发布更新日志（需管理密码）
  • 自建房间服务器：cd listen-together-server && npm install && node index.js
  • App 设置 → 其他 → 一起听服务器地址，填 ws://你的服务器:23333（自编译需自配签名）
  • 网页版直接访问 http://你的服务器:23333/
  • 详细说明见源码包 listen-together-server/README.md
